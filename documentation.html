UWU AI-Based Smart Procurement System

Comprehensive software documentation for the SaaS Multi-Tenant MERN Stack Procurement Platform.

1. System Overview

The UWU Smart Procurement System is a modern, enterprise-grade Software as a Service (SaaS) application designed to streamline, automate, and intelligentize the procurement lifecycle. It provides end-to-end management from requisition and tendering to contract management and payments, all augmented by advanced Artificial Intelligence (AI) capabilities.

Key AI features include Predictive Market Alerts, Automated Bid Evaluation, and AI Explainability to ensure transparent decision-making.

2. Architecture & Tech Stack

The system is built using a modern JavaScript/TypeScript ecosystem organized as a Monorepo using TurboRepo. This allows seamless code sharing between the frontend, backend, and shared packages.

Frontend (`apps/web`)

  • Framework: React 19 + Vite
  • State Management: Redux Toolkit
  • Styling: Tailwind CSS v4
  • Routing: React Router v7
  • Forms & Validation: React Hook Form + Yup
  • Charts: Recharts

Backend (`apps/api`)

  • Runtime: Node.js
  • Framework: Express.js 5
  • Database: MongoDB via Mongoose v9
  • AI/ML Integration: ml-random-forest, natural (NLP)
  • Authentication: JWT & bcryptjs
  • Security: Helmet, express-rate-limit, xss-clean

Shared Packages (`packages/`)

  • ui/: Shared UI components
  • types/: Shared TypeScript definitions (if applicable)
  • validation/: Shared validation schemas

3. Core Modules

1. Authentication & Role Management

Supports multi-tenant architectures with Role-Based Access Control (RBAC). Differentiates between Admins, Procurement Officers, Vendors, and Finance.

2. Procurement & Tendering

End-to-end creation and approval of procurement requests. Automated publishing of Tenders based on approved procurements. Vendors can submit bids directly through their portal.

3. AI Intelligence Module

Utilizes Machine Learning to analyze market trends and generate Market Alerts. Includes an AI Explainability Log to justify automated vendor scoring or bid ranking.

4. Contract & Payment Management

Digital contract generation and tracking. Milestone-based payment tracking integrated with procurement milestones.

5. Document Processing

Automated parsing of vendor PDFs and invoices using pdf-parse. Cloud-based storage via Cloudinary.

6. Communication

In-app messaging system between vendors and procurement officers, supplemented by an automated notification engine (Email via Nodemailer & In-app alerts).

4. Database Schema (Models)

The MongoDB database comprises the following core collections:

Model Name Description
User / RoleSystem users and their RBAC permissions.
VendorExternal suppliers registered on the platform.
ProcurementInternal purchase requisitions and approvals.
Tender / BidPublic/Private requests for proposals and vendor submissions.
Contract / PaymentAgreements awarded to vendors and financial transactions.
DocumentMetadata and URLs for uploaded PDFs and images.
MarketAlertAI-generated insights on pricing and supply chain risks.
AiExplainabilityLogAudit trail of decisions made by the ML models.
AuditLogSystem-wide tracking of user actions for compliance.

5. API Reference

The RESTful API is structured around business entities. Base URL: /api/v1

  • /auth/* - Login, Registration, Token Refresh
  • /users/* - User management
  • /vendors/* - Vendor onboarding and profiles
  • /procurement/* - Requisitions lifecycle
  • /tender/* & /bid/* - Tendering process
  • /ai/* - Fetch market alerts and run predictive models
  • /document/* - File uploads and parsing
  • /report/* - Generate analytical reports

6. Getting Started (Development)

The project uses turbo to run scripts across the monorepo.

# Install dependencies at the root
npm install

# Start the development servers (Frontend & Backend)
npm run dev

# Build for production
npm run build

Ensure your .env file in the root and apps/api/.env are properly configured with your MongoDB URI, JWT Secret, and Cloudinary credentials.
